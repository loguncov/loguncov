## Обо мне

Работаю с системным и прикладным программированием, автоматизацией и прототипированием. В проектах использую **C++**, **Python**, **JavaScript**, **C#**, Arduino и готовые API.

Основные направления:

- **C / C++** — алгоритмы, парсеры, индексаторы и прикладные инструменты;
- **Python / AI** — Telegram-боты и интеграции с языковыми моделями;
- **Embedded / IoT** — Arduino, прошивки и автоматизация оборудования;
- **Web / AR** — браузерные интерфейсы и работа с 3D-контентом;
- **GameDev** — проекты на Unity и Unreal Engine 5.

В работе стараюсь делать решения понятными, документированными и пригодными для дальнейшего развития.
